# mergedesk-sample

Public sample pull request used to demo [MergeDesk](https://github.com/AdityaKrSingh26/MergeDesk). This is not the MergeDesk app.

Paste the open pull request into https://mergedesk-pihi.onrender.com

Live desk URL for this sample: https://github.com/AdityaKrSingh26/mergedesk-sample/pull/1

The issue on `main` asks for a 2000ms retrying fetch, host-only save-as-image, and a guest lock in tour and doctor modes. The pull request is the kind of agent patch MergeDesk is built to orient: extra surface area, a timeout that does not match the issue, and an invented package import.
